## Introduction to Pandas DataFrames – Replicating an article in Markdown

This repository contains a replication of the article *Introduction to Pandas DataFrames* as a Jupyter Notebook, using Markdown for the text and code cells for the Python examples.

| File | Purpose |
|---|---|
| [`Pandas.ipynb`](Pandas.ipynb) | Jupyter Notebook containing the replicated article, with Markdown cells for the text and executed code cells (including outputs) for the five Python examples. |
| [`dist/Pandas.html`](dist/Pandas.html) | HTML export of the final notebook, which can be opened in any web browser without Jupyter. |
| [`Pandas.webp`](Pandas.webp) | Image embedded at the top of the notebook. A copy is stored in `dist/` so that the image is also displayed in the HTML export. |
